# 📖 About

As an **IT Support Engineer** with experience in **Cloud (AWS), Networking, System Administration, and IT Operations**, I'm expanding my professional profile into **Full Stack Development**.

This repository serves as a structured learning journal where I document every stage of my progress through practical exercises, coding challenges, and increasingly complex web applications.

Rather than showcasing only finished applications, this repository reflects my learning process, continuous improvement, and commitment to writing clean, maintainable code while building a solid foundation in modern web development.

My long-term objective is to combine my infrastructure and cloud background with software development skills to become a well-rounded engineer capable of designing, deploying, and maintaining complete web solutions.
