## Proyectos Destacados

### 1. Portal de Arriendos (Full Stack con Django)
Tecnologías: Python, Django, Django ORM, Bootstrap 5, SQLite  
Descripción: Aplicación web completa para la gestión de arriendos de inmuebles. Permite a los arrendadores publicar y administrar sus propiedades, mientras que los arrendatarios pueden explorar la oferta disponible con filtros geográficos dinámicos.  
Características Clave (Cumplimiento de Hitos 4 y 5):
- Sistema de autenticación (Login/Registro) con perfiles diferenciados y redirección de URLs.
- Página de perfil personal para desplegar y modificar datos personales (CRUD de usuario).
- CRUD completo de inmuebles con validación de permisos (solo el dueño puede editar/borrar).
- Filtrado dinámico y dependiente por Región y Comuna utilizando consultas optimizadas del ORM.
- Scripts personalizados para el poblado de datos geográficos (poblar_datos.py) y generación de reportes analíticos (reportes.py).
- Diseño 100% responsivo y profesional con Bootstrap 5.

### 2. Proyectos Frontend (Viajes Chile, Ricomida, Suricata, etc.)
Tecnologías: HTML5, CSS3, Bootstrap 5, jQuery  
Descripción: Sitios web estáticos responsivos desarrollados aplicando buenas prácticas de maquetación, diseño mobile-first y componentes nativos de Bootstrap.
