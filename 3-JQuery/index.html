🎨 Muestrario jQuery

Todos los efectos principales en una sola página

1. Hide / Show / Toggle

Ocultar, mostrar o alternar la visibilidad de elementos instantáneamente o con animación.

Soy un box
// Ocultar/mostrar con velocidad
$("#hideTarget").hide(1000);
$("#hideTarget").show("slow");
$("#hideTarget").toggle();

2. Fade In / Fade Out / Fade Toggle

Desvanecer elementos modificando su opacidad suavemente.

Fade Box
$("#fadeTarget").fadeIn(1000);
$("#fadeTarget").fadeOut("slow");
$("#fadeTarget").fadeTo(1000, 0.5);

3. Slide Up / Slide Down / Slide Toggle

Deslizar elementos hacia arriba o abajo modificando su altura.

Slide Box
$("#slideTarget").slideUp(1000);
$("#slideTarget").slideDown("fast");
$("#slideTarget").slideToggle();

4. Animate (Animación Personalizada)

Animar propiedades CSS numéricas como posición, tamaño, márgenes, etc.

Animate
$("#animateBox").animate({
  left: "+=200",
  width: "150px",
  opacity: 0.5
}, 1000);

5. Delay (Retraso entre efectos)

Hacer pausas entre efectos encadenados. ¡Solo funciona con efectos!

Delay Box
$("#delayTarget")
  .slideUp(500)
  .delay(2000)
  .slideDown(500);

6. Toggle Class (Cambiar clases CSS)

Agregar o remover clases CSS para cambiar estilos dinámicamente.

Toggle Class
$("#classTarget").toggleClass("active");
$("#classTarget").addClass("highlight");
$("#classTarget").removeClass("highlight");

7. Callback (Función después del efecto)

Ejecutar código cuando un efecto termina completamente.

Callback
$("#callbackTarget").fadeOut(1000, function() {
  alert("¡Efecto terminado!");
  $(this).fadeIn();
});

8. Chain (Encadenar múltiples efectos)

Encadenar varios efectos y métodos en una sola línea.

Chain
$("#chainTarget")
  .slideUp(300)
  .delay(500)
  .slideDown(300)
  .css({ background: "red" });
