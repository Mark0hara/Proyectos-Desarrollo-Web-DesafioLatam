# Proyecto Inmobiliaria - Hito 1: Conectando Django a una base de datos

## Descripción
Este proyecto consiste en el desarrollo de un sitio web para una empresa de arriendo de inmuebles. Se ha configurado un entorno de desarrollo con Django y PostgreSQL, implementando un modelo de datos relacional con claves foráneas y operaciones CRUD completas.

## Requerimientos del Entorno
- Python 3.x
- PostgreSQL
- Django
- psycopg2-binary
